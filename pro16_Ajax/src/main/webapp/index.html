키 없이 만드는 날씨 사이트

이 프로젝트에는 준비물이 없습니다.
회원가입, 인증키 발급, 활성화 대기(최대 2시간), 신용카드 등록이 전혀 필요 없습니다. 톰캣을 실행하고 아래 순서대로 클릭하면 바로 실제 날씨가 나옵니다.

혼자 실습하는 순서

아래 자습서를 열고 1장부터 순서대로 따라가면 3단계를 거쳐 완성본이 만들어집니다.

📘 자습서 열기 (여기부터 시작하세요)

단계별 예제

단계내용새로 배우는 것완성 모습
1 좌표를 고정해서 날씨 조회 fetch 기본 구조, try catch finally 서울의 현재 기온이 표시됩니다
2 도시 이름으로 날씨 조회 요청 두 개를 순서대로 이어서 호출 도시를 검색해 날씨를 봅니다
3 완성본 (날씨 + 미세먼지 + 주간예보) Promise.all 로 동시 호출 포트폴리오에 넣을 수 있는 화면

jQuery 버전 (같은 화면을 다른 문법으로)

위 3단계와 화면도 동작도 완전히 같고 문법만 jQuery 로 바꾼 것입니다. 같은 번호끼리 나란히 열어 비교하면 두 방식의 차이가 한눈에 보입니다.

단계jQuery 버전새로 배우는 것짝 파일
1 jq1.html $.ajax 기본 구조 step1.html 과 비교
2 jq2.html 콜백 중첩(콜백 지옥) 직접 확인 step2.html 과 비교
3 jq3.html $.when 동시 호출과 [0] 함정 step3.html 과 비교

사용하는 API 세 가지

[1] 지오코딩 : 도시 이름을 위도와 경도로 바꿔 줍니다
https://geocoding-api.open-meteo.com/v1/search?name=Busan&count=5&language=ko

[2] 날씨 : 위도와 경도를 넣으면 현재 날씨와 주간 예보를 돌려줍니다
https://api.open-meteo.com/v1/forecast?latitude=35.18&longitude=129.07¤t=temperature_2m&timezone=Asia/Seoul

[3] 대기질 : 위도와 경도를 넣으면 미세먼지 농도를 돌려줍니다
https://air-quality-api.open-meteo.com/v1/air-quality?latitude=35.18&longitude=129.07¤t=pm10,pm2_5

세 주소 모두 브라우저 주소창에 그대로 붙여넣으면 결과를 바로 볼 수 있습니다.
인증키를 붙이지 않아도 됩니다.
가장 많이 틀리는 부분을 미리 알려 드립니다.
지오코딩은 도시 이름을 영문으로 검색해야 합니다.
name=Seoul 로 검색하면 서울특별시가 나오지만, name=서울 처럼 한글로 검색하면 결과가 하나도 나오지 않습니다.
대신 language=ko 를 붙이면 결과 이름은 한글로 옵니다.
