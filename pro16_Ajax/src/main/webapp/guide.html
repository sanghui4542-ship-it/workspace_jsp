▶ 1단계 화면 열기

반드시 외워야 하는 형태

fetch 를 쓰는 모든 코드는 아래 6줄 구조를 벗어나지 않습니다. 통째로 외우세요.

async function 함수이름() { try { const res = await fetch(주소); // 1. 요청 보내기 if (!res.ok) throw new Error(res.status); // 2. 상태 검사 (필수) const data = await res.json(); // 3. 내용물 꺼내기 // 4. 화면의 특정 부분만 갱신 } catch (err) { // 5. 사용자 안내 + console.error } finally { // 6. 버튼 복구 등 뒷정리 } }

각 줄의 의미

문법의미
async이 함수 안에서 await 를 쓰겠다고 미리 선언하는 표시입니다.
await결과가 나올 때까지 이 함수 안에서만 기다립니다. 화면 전체가 멈추는 것이 아닙니다.
res.ok상태코드가 200~299 이면 true 입니다. fetch 는 404, 500 을 오류로 보지 않으므로 반드시 직접 검사해야 합니다.
res.json()서버가 보낸 글자를 자바스크립트 객체로 바꿔 줍니다. await 를 빼먹으면 화면에 [object Promise] 가 찍힙니다.
finally성공하든 실패하든 반드시 실행됩니다. 버튼 잠금 해제를 여기에 씁니다.
⚠️ 초보자가 가장 많이 하는 실수 3가지
1. await 빠뜨리기 → 화면에 [object Promise] 라는 글자가 나옵니다.
2. res.ok 검사 생략 → 서버가 오류를 보냈는데 정상으로 착각해 엉뚱한 곳에서 헤맵니다.
3. 버튼 복구를 try 안에 쓰기 → 오류가 나면 버튼이 영원히 잠깁니다.

3장. 응답 구조를 읽는 법

💡 왜 하나요?
API 마다 응답 구조가 다릅니다. 구조를 읽는 법만 익히면 처음 보는 API 도 혼자 붙일 수 있습니다. 이것이 이 자습서에서 가장 중요한 장입니다.

1단계 - 대괄호인가 중괄호인가

시작 기호종류꺼내는 법
[ 대괄호배열 (목록)순서로 꺼냅니다. data[0] · 첫 칸은 0번입니다
{ 중괄호객체이름으로 꺼냅니다. data.current

2단계 - 점을 몇 번 찍어야 하는지 세기

날씨 API 의 응답은 이렇게 생겼습니다.

{ "timezone": "Asia/Seoul", "current": { "time": "2026-09-04T19:45", "temperature_2m": 24.7, "relative_humidity_2m": 68 } }

기온 값 24.7 을 꺼내려면 current 를 거쳐 temperature_2m 으로 가야 합니다.

data.temperature_2m // 틀림. undefined 가 나옵니다 data.current.temperature_2m // 맞음. 24.7 이 나옵니다

3단계 - 배열이 섞여 있으면 번호를 붙이기

지오코딩 응답은 results 가 배열입니다.

{ "results": [ { "name": "부산광역시", "latitude": 35.10168, "longitude": 129.03004 } ] }
data.results.latitude // 틀림. results 는 배열입니다 data.results[0].latitude // 맞음. 첫 칸을 꺼낸 뒤 이름으로 접근
⚠️ 주간 예보는 구조가 특이합니다
날짜별로 객체가 나열된 것이 아니라, 항목별로 배열이 따로 들어 있습니다.
"daily": { "time": ["2026-09-04", "2026-09-05", "2026-09-06"], "temperature_2m_max": [28.1, 26.4, 24.0 ], "temperature_2m_min": [21.3, 20.8, 19.5 ] } 같은 위치의 칸끼리 짝을 이룹니다. 0번 칸 : 2026-09-04 최고 28.1 최저 21.3 1번 칸 : 2026-09-05 최고 26.4 최저 20.8 그래서 time 을 기준으로 반복하며 같은 번호(i)로 다른 배열을 꺼냅니다.

💡 왜 요청을 두 번 보내나요?

  3. 자주 쓰는 도시 버튼(서울, 도쿄 등)을 눌러 봅니다.

5장. 3단계 실습 - 완성본 만들기

동시 호출을 쓰면 시간이 절반이 됩니다

[순차로 했다면] 0초 1초 2초 |==날씨====|==대기질===| 총 2초 [Promise.all 로 하면] 0초 1초 |==날씨====| |==대기질===| 총 1초 날씨와 대기질은 둘 다 좌표만 있으면 되고 서로 관계가 없으므로 동시에 보내는 것이 맞습니다.

Promise.all 문법

const [날씨응답, 대기응답] = await Promise.all([ fetch(날씨주소), fetch(대기주소) ]);
구조 분해 할당
const [a, b] = 배열 은 배열의 0번, 1번 값을 각각 a, b 에 한 번에 담습니다.
결과는 "먼저 끝난 순서" 가 아니라 "배열에 넣은 순서" 대로 담깁니다. 순서가 뒤바뀌지 않습니다.
⚠️ Promise.all 의 성질
둘 중 하나라도 실패하면 전체가 실패합니다. 성공한 것만이라도 받고 싶다면 Promise.allSettled 를 씁니다.

증상별 원인표

F12 개발자도구 사용법

  1. 화면에서 키보드 F12 를 누릅니다.
  2. Console 탭 : 빨간 글씨가 있으면 자바스크립트 오류입니다. 몇 번째 줄인지도 알려 줍니다.
  3. Network 탭 : 조회 버튼을 누르면 요청 목록이 나타납니다.
  4. 요청 한 줄을 클릭하면 Status 에 상태코드 숫자가 보입니다.
  5. Response 탭을 누르면 서버가 실제로 보낸 내용을 그대로 볼 수 있습니다.
✅ 판단 기준
Status 가 200 이고 Response 에 값이 보이면 통신은 정상입니다. 그런데도 화면에 안 나오면 자바스크립트 코드 문제이므로 Console 탭을 봅니다.
